Popular topics

“Can’t verify the developer” on first launchOpen System Settings → Privacy & Security, scroll down and click Open Anyway. You only need to do this once.
Stashbar isn’t spotting linksCheck Settings → General → Watch clipboard. Links copied from password managers are ignored on purpose.
Change the ⌥S shortcutSettings → Shortcuts. Click the key and pick a new combo.
Links not syncingMake sure you’re signed in on both Macs with the same Google account, then Settings → Account → Sync now.
Quit Stashbar fullyRight-click the pin in the menu bar → Quit Stashbar. Nothing keeps running afterwards.
Import bookmarksExport bookmarks as HTML from Safari, Chrome, Arc or Firefox, then Settings → Data & privacy → Import.
